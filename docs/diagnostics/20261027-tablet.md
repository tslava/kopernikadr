# Tablet session 1 — 2026-10-27

The first run of the 0b probes on the real tablet. The g05 was unavailable (Family Link downtime),
so the owner's **Pixel 8** (Android 17) ran the camera app (`.probe` build, installed with
`adb install -r`). The Redmi 10 (MIUI 14) refused the install: MIUI's "Install via USB" needs a
SIM card.

- Tablet: Lenovo Tab M10 3rd gen TB328FU, Android 12, WebView 155.0.8059.43, 4 GB RAM, **4.7 GB
  free (92 % used)**.
- Remote: `pl.slava.kopernikadr.remote.debug` installed with `install.sh --remote-only --variant debug`.
- Raw reports: `20261027-tablet/{1-fake-camera,2-pixel8,3-pixel8-reconnect}.json`.

## Results (tablet → Pixel 8 over home Wi-Fi)

All 8 probes passed (run 3).

| Probe | Result |
|---|---|
| env | secure context, VideoEncoder/Decoder, VideoFrame, ImageDecoder, crypto.subtle — nothing missing |
| NSD | found the camera in 438 ms (Pixel); the Mac `dns-sd -R` fake in 605 ms |
| camera preview low / normal / high | 8.5 / 6.7 / 5.6 fps; latency p50 96 / 126 / 147 ms; 640×480 / 960×720 / 1280×960; 0 stalls |
| capture | 387 ms round trip, 3264×2448 full ≈ 1.85 MB |
| download (native) | 0.4–0.6 s per full (3–4.4 MB/s), size + sha256 OK, `installFile` OK, acked 2/2 |
| VideoFrame | `convertFileSrc` → 3264×2448 RGBX frame; decode 104 ms |
| export (Mediabunny, **avc1.640028 High, hardware**) | 20 frames 3.0 s; 100 frames 11.8 s = 118 ms/frame (1.06× real time at 8 fps); decode of the 8 MP JPEG ≈ 220 ms/frame is the bottleneck, encode ≈ 1 ms; probe acked its 20 frames |
| reconnect: screen lock | camera went offline 13.6 s after the prompt, back online before "Dalej"; **`bootId` changed** |
| reconnect: camera app restart | offline after 7 s, reconnected 3.8 s after the app was back; `bootId` changed |

With the Mac fake camera (simple 1440×1080 pictures) the same export ran at 45 ms/frame, which
confirms the time goes into JPEG decode, not encoding.

## Decisions

- **Export path: WebCodecs + Mediabunny, AVC High.** The T610 encodes in hardware; the native
  MediaCodec export (conditional item in Task 12) is **not needed**.
- ➕ Speed-up for stage 1: decode `play` (1440×1080, already made on the phone) instead of `full`
  for export — export is 1440×1080 anyway; the fake-camera run suggests ≈ 3× faster.
- **NSD: own `KopernikadrNsd` plugin** works on the tablet (Android 12, serial `resolveService`).
- The camera server restarts on a screen lock (new `bootId`); the remote reconnects on its own.
  Expected with the server tied to the activity; revisit if it disturbs shooting.
